# Лабораторна робота №3

## Тема
Нездатні до змін структури даних (immutability) у Python.

## Варіант 1
Замовлення інтернет-магазину.

## Мета роботи
Навчитися використовувати незмінні структури даних Python та реалізовувати чисті функції оновлення об'єктів.

## Реалізація
У роботі використано:
- tuple для зберігання товарів;
- frozenset для зберігання тегів;
- @dataclass(frozen=True, slots=True) для моделей Item та Order;
- MappingProxyType для захисту метаданих;
- dataclasses.replace для створення нових копій об'єктів.

Реалізовано додавання товару, додавання тегу та зміну статусу оплати без зміни початкового замовлення.

## Тестування
За допомогою pytest перевірено:
- правильність обчислення суми замовлення;
- відсутність мутацій;
- незмінність моделей;
- захист метаданих від змін;
- можливість хешування об'єктів.

Для перевірки часу виконання використовується pytest --durations=5.

## Висновок
Під час роботи освоєно незмінні структури даних Python. Реалізовано чисті функції оновлення та перевірено їхню коректність за допомогою тестів.

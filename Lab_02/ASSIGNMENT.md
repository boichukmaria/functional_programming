# Лабораторна робота №2

## Тема
Функції вищого порядку, lambda, композиція.

## Варіант 1
Клієнти інтернет-магазину.

## Завдання
Побудувати функціональний конвеєр перетворень над списком клієнтів без мутації вхідних даних.

## Структура запису
- id — ідентифікатор клієнта;
- name — ім'я клієнта;
- age — вік клієнта;
- city — місто;
- purchases — список покупок.

## Конвеєр перетворень
1. Відфільтрувати повнолітніх клієнтів.
2. Обчислити загальну суму покупок.
3. Підсилити суму для вибраного міста.
4. Відсортувати записи за сумою покупок за спаданням.
5. Взяти Top-N клієнтів.

## Агрегація
За допомогою reduce обчислити:
- count;
- sum_total;
- avg_total.

## Критерії виконання
- Використання TypedDict.
- Не менше чотирьох чистих трансформацій.
- Використання map, filter та lambda.
- Реалізація compose або pipe.
- Сортування за двома ключами.
- Формування Top-N.
- Реалізація reduce-агрегації.
- Написання тестів pytest.
- Перевірка black, ruff та mypy.

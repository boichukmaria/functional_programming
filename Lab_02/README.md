# Лабораторна робота №2

## Тема
Функції вищого порядку, lambda, композиція.

## Варіант
1 — Клієнти інтернет-магазину.

## Мета роботи
Навчитися використовувати функції вищого порядку, lambda, map, filter, reduce та композицію функцій для створення функціонального конвеєра без зміни вхідних даних.

## Реалізація
У роботі реалізовано:
- опис клієнтів за допомогою TypedDict;
- фільтрацію повнолітніх клієнтів;
- обчислення суми покупок;
- підсилення суми для вибраного міста;
- нормалізацію імен;
- сортування та формування Top-N;
- агрегацію за допомогою reduce.

## Структура проєкту
- Lab_02/lab2.py — функції та конвеєр;
- Lab_02/main.py — запуск програми;
- Lab_02/sample_data.json — вхідні дані;
- tests/test_lab2.py — тести;
- ASSIGNMENT.md — опис завдання.

## Встановлення залежностей

```bash
pip install -r requirements.txt
```

## Запуск тестів

```bash
pytest -q
```

## Запуск програми

```bash
py -m Lab_02.main --data Lab_02/sample_data.json --top 3
```

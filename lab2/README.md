# Лабораторна робота №2

Варіант 1. Клієнти інтернет-магазину.

## Мета
Навчитися використовувати функції вищого порядку,
lambda, map, filter, reduce та композицію функцій.

## Виконання
Реалізовано фільтрацію клієнтів за віком,
обчислення суми покупок, коефіцієнт для міста,
сортування та вибір Top-N.

## Запуск
1. Встановити залежності:
   pip install -r requirements.txt

2. Запустити програму:
   python app.py

3. Запустити тести:
   python -m pytest

# Лабораторна робота №1

## Тема
Основи функціонального програмування у Python.

## Варіант 1
Обробка замовлень інтернет-магазину.

## Що реалізовано
- Обчислення вартості товарів у замовленні.
- Відбір оплачених замовлень за мінімальною сумою.
- Застосування знижки та податку через Callable.
- Створення нових словників без зміни вхідних даних.
- Відокремлення обчислень від виведення результатів.
- Автоматичні тести для перевірки програми.

## Структура проєкту
- `core.py` — функції обчислення.
- `app.py` — запуск програми та виведення результатів.
- `tests/test_core.py` — тести.
- `requirements.txt` — необхідні інструменти.

## Запуск
```bash
python app.py
```

## Запуск тестів
```bash
python -m pytest -v
```

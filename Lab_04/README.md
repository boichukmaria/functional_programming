### Рекурсія та мемоізація

Рекурсивні функції викликають самі себе для розв'язання менших підзадач. Кожна рекурсивна функція має базовий випадок і рекурсивний крок.

Для уникнення повторних обчислень використовується мемоізація за допомогою `@lru_cache(maxsize=None)`. Результати вже виконаних обчислень зберігаються в кеші та використовуються повторно.

У роботі реалізовано рекурсивну та ітеративну версії обчислення чисел Трібоначчі.

Для перевірки кешу використовуються `cache_info()` та `cache_clear()`.

### Порівняння алгоритмів

Час виконання рекурсивної та ітеративної версій обчислення чисел Трібоначчі порівнюється для n = 20, 30 та 35.

Мемоізація зменшує кількість повторних обчислень, оскільки кожне значення послідовності зберігається в кеші. Без кешування однакові підзадачі обчислювалися б багаторазово.

### Обмеження рекурсії

У Python існує обмеження глибини рекурсії, яке можна перевірити за допомогою `sys.getrecursionlimit()`. При перевищенні цього обмеження виникає `RecursionError`.

CPython не підтримує оптимізацію хвостової рекурсії (TCO), тому навіть хвостові рекурсивні виклики не перетворюються автоматично на цикли.

Для глибоких обчислень безпечніше використовувати ітеративні алгоритми.

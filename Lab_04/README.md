# Лабораторна робота №4
## Рекурсія та мемоізація в Python

**Варіант 1 — Числові послідовності**

### Мета роботи

Ознайомитися з рекурсією та мемоізацією в Python, навчитися використовувати декоратор `lru_cache`, реалізувати рекурсивні й ітеративні алгоритми та порівняти їхню ефективність.

### Структура проєкту

- `algorithms.py` — реалізація алгоритмів QuickSort, обходів бінарного дерева, чисел Фібоначчі та Трібоначчі.
- `benchmark.py` — порівняння часу виконання алгоритмів Трібоначчі.
- `tests/test_quicksort.py` — тести сортування.
- `tests/test_tree.py` — тести обходів дерева.
- `tests/test_fib.py` — тести чисел Фібоначчі.
- `tests/test_tribonacci.py` — тести чисел Трібоначчі.
- `requirements.txt` — залежності проєкту.
- `pyproject.toml` — налаштування інструментів.
- `mypy.ini` — налаштування перевірки типів.

### Рекурсія та мемоізація

Рекурсивні функції викликають самі себе для розв'язання менших підзадач. Для уникнення повторних обчислень використовується мемоізація за допомогою `@lru_cache(maxsize=None)`.

У роботі реалізовано рекурсивну та ітеративну версії обчислення чисел Трібоначчі.

### Обмеження рекурсії

У Python існує обмеження глибини рекурсії, яке можна перевірити за допомогою `sys.getrecursionlimit()`. Також CPython не підтримує оптимізацію хвостової рекурсії (TCO), тому для глибоких обчислень безпечніше використовувати ітеративні алгоритми.
